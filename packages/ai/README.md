# Fournisseurs IA

## Responsabilité

Encapsuler les fournisseurs configurés, valider leurs sorties et appliquer les limites de coût et de confidentialité.

## État

Structure réservée, aucune API d'exécution exposée pendant l'initialisation.

## Entrées/sorties prévues

Entrée : données minimisées et instruction versionnée. Sortie : réponse structurée validée ou erreur explicite.
