# Moteur de correspondance

## Responsabilité

Calculer un score indicatif et explicable entre un CV et une offre.

## État

Structure réservée, aucune API d'exécution exposée pendant l'initialisation.

## Entrées/sorties prévues

Entrée : faits du CV et exigences de l'offre. Sortie : score, détail, compétences présentes et manquantes.
