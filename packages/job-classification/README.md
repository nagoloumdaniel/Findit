# Classification des offres

## Responsabilité

Valider contrat, métier, localisation et risques avant publication.

## État

Structure réservée, aucune API d'exécution exposée pendant l'initialisation.

## Entrées/sorties prévues

Entrée : offre normalisée. Sortie : décision expliquée d'acceptation, rejet ou quarantaine.
