# Normalisation des offres

## Responsabilité

Transformer une offre brute en données homogènes sans inventer de valeur manquante.

## État

Structure réservée, aucune API d'exécution exposée pendant l'initialisation.

## Entrées/sorties prévues

Entrée : offre brute sourcée. Sortie : offre normalisée avec preuves et champs inconnus explicites.
