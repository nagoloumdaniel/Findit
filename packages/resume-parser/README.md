# Analyse des CV

## Responsabilité

Extraire des faits présents dans un CV autorisé sans compléter les informations absentes.

## État

Structure réservée, aucune API d'exécution exposée pendant l'initialisation.

## Entrées/sorties prévues

Entrée : fichier PDF ou DOCX validé. Sortie : faits structurés et avertissements d'extraction.
