# Connecteurs d'offres

## Responsabilité

Accéder uniquement aux sources autorisées et produire des offres brutes traçables.

## État

Structure réservée, aucune API d'exécution exposée pendant l'initialisation.

## Entrées/sorties prévues

Entrée : configuration d'une source autorisée. Sortie : offre brute accompagnée de sa provenance.
