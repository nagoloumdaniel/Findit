# Déduplication des offres

## Responsabilité

Identifier les publications correspondant à une même offre et conserver toutes les sources.

## État

Structure réservée, aucune API d'exécution exposée pendant l'initialisation.

## Entrées/sorties prévues

Entrée : offres validées. Sortie : groupes de doublons et décisions de fusion réversibles.
